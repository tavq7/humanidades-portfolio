# From practice to targeted review
## De la práctica al repaso dirigido

Public portfolio overview of an independent university entrance preparation prototype. The full application source and question banks are private. This repository contains no application code or complete question bank.

## The learning problem

A correct answer can hide a guess. A wrong answer needs a useful next step. The prototype connects daily study planning, subject practice, review cards and progress statistics. Progress is kept locally in the learner's browser and can be exported.

## Proposed learning sequence

| Step | Learner experience | Purpose |
|---|---|---|
| Practice | Answer and mark uncertainty | Make guesses visible |
| Review | Revisit an error or a doubtful answer | Identify a gap |
| Explain | Read feedback and prepare a review card | Connect the answer to reasoning |
| Transfer | Try a new item on the same skill | Check understanding with new material |

This table illustrates a learning approach. It does not report measured outcomes or export the underlying question bank. This is an independent prototype, not an official university product.

## Possible institutional pilot

One focused reading-comprehension unit: two original short texts, six questions and explanatory feedback. An academic lead selects the learner difficulty and reviews the material. Scope, fee, revisions, delivery dates and permitted uses must be agreed before work begins. Software adaptation is a separate scope.

**Para instituciones:** un posible piloto pagado aborda una dificultad concreta de comprensión lectora mediante dos textos breves originales, seis preguntas y explicaciones. El equipo académico define la necesidad y revisa el material. Alcance, honorarios y derechos de uso se acuerdan antes de iniciar.
